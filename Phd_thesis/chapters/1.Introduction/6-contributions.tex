\section{Contributions}
In this section, we summarize the contributions made to the literature as part of this dissertation. They can be divided into three main areas: (1) development of new simulation tools for marine robotics, (2) novel inspection path planners, and (3) data-driven modeling techniques. All these methods directly contribute to MPC performance and usability, as they improve accuracy, adaptability, and safety.

\noindent \textbf{[C1] Simulation}  
Provides the foundational platform for development and validation. \textbf{C1.1: Visually Realistic Underwater Robot Simulator:} Development of a simulation environment combining realistic visual rendering with accurate hydrodynamic modeling to reduce the sim-to-real gap.

\vspace{0.5em}

\noindent \textbf{[C2] Control and Planning}  
Develops novel algorithms for safe and effective autonomous navigation and task execution. \textbf{C2.1: A real-time entanglement-Aware Path Planning:} An entanglement-aware path planner for tethered underwater inspection tasks. \textbf{C2.2: Visual Tracking \ac{NMPC} Formulation:} An \ac{NMPC} strategy that explicitly incorporates visual tracking objectives, optimizing inspection quality and coverage.

\vspace{0.5em}

\noindent \textbf{[C3] Model Learning}  
Enhances controller performance by improving the fidelity of the underlying dynamic models. \textbf{C3.1: Learning Full Model Dynamics using PINNs:} Exploration of physics-informed neural networks  for learning full dynamic models from data while respecting physical laws. \textbf{C3.2: Learning Model Residuals:} Online estimation of model uncertainties and external disturbances using Gaussian Processes to adaptively augment the nominal model used within the \ac{MPC}.
